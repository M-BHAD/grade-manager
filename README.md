# Grade Manager 📊

A beginner-friendly Python project that calculates a student's total marks, percentage, and grade based on their subject-wise marks.

## About the Project

Grade Manager is a simple command-line application built using Python. It takes a student's name and marks in different subjects as input, then calculates their academic performance.

This project helped me practise Python fundamentals and understand how to use conditional statements, loops, and arithmetic operations in a practical application.

## Features

* Accepts the student's name.
* Takes marks in English, Hindi, Mathematics, Science, and Computer Science.
* Calculates total marks and percentage.
* Assigns a grade based on the percentage.
* Validates marks to ensure they are within the permitted range.
* Uses loops to handle input validation.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3 on your computer.

2. Clone or download this repository.

3. Open the project folder in VS Code.

4. Open the terminal and run:

   ```bash
   python hub.py
   ```

5. Enter your name and subject-wise marks when prompted.
